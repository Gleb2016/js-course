1) Чем let отличаеться от const? Что именно запрещает const?
let позволяет переписывать переменной новые значения.
const запрещает переписывание (нельзя свзять с дургим значением)
2) Почему typeof null возращает "object"?
Это историческая ошибка, которая осталась с первой версии языка JavaScript (1995 года). В первых реализациях null имел тот же тип-тег, что и объекты. Исправить это сейчас нельзя, потому что на этом поведении построено слишком много существующего кода в интернете. Это нужно просто запомнить как исключение.
3) Почему 0.1 + 0.2 !== 0.3 и как правильно хранить деньги,
Компьютер хранит числа в двоичной системе, а дробь 0.1 в ней бесконечна (как 1/3 в десятичной). Из-за ограничений памяти она округляется, и при сложении двух таких чисел ошибка накапливается.
Как хранить деньги: Считать всё в целых числах (в копейках), а при выводе для пользователя просто делить на 100 и применять toFixed(2).
4) Какие значения в JavaScript считаються ложными?
Ложных (falsy) значений ровно шесть:
fale, 0 (число ноль), "" (пустая строка), null, undefined, NaN
Всё остальное в JavaScript считается истинным (включая строку "0", пустой массив [] и пустой объект {}).
5) Что вернёт выражение "" || 'нет' и выражение "" ?? 'нет'? Почему?
"" || 'нет' вернёт 'нет'. Оператор || (ИЛИ) возвращает второй операнд, если первый является ложным. Пустая строка — ложное значение, поэтому возвращается 'нет'.
"" ?? 'нет' вернёт "" (пустую строку). Оператор ?? (нулевого слияния) подставляет значение по умолчанию только если слева стоит null или undefined. Пустая строка не является ни тем, ни другим, поэтому она остается.
6) Чем Number('12px') отличается от parseInt('12px')?
Number('12px') пытается преобразовать строку целиком. Из-за наличия букв "px" он не может этого сделать и возвращает NaN.
parseInt('12px') читает строку слева направо, пока получается число. Он извлечёт число 12, а буквы "px" молча отбросит. Вернёт 12.
7) Почему полсе const b = a изменение массива b виднно в a?
Потому что массивы и объекты передаются по ссылке. Переменная a хранит не сам массив, а адрес в памяти, где он лежит. Строка const b = a копирует именно этот адрес (ссылку). Теперь обе переменные указывают на один и тот же массив в памяти, поэтому изменения через b видны через a.
8) Что будет в swith, если забыть break?
Произойдёт «проваливание» (fall-through). После совпадения с нужным case код начнёт выполняться дальше, игнорируя условия следующих case, и будет выполняться до тех пор, пока не встретит break или не закончится блок switch.
9) Чем while отличается от do...while?
while проверяет условие до выполнения тела цикла. Если условие изначально ложно, цикл не выполнится ни разу.
do...while проверяет условие после выполнения тела. Поэтому его тело всегда гарантированно выполнится хотя бы один раз, даже если условие сразу ложно.
10) Что показывают панели Scope, Watch и Call Stack в отладчике?
Scope (Область видимости): Показывает все переменные, доступные в текущий момент выполнения программы (локальные, глобальные, замыкания) и их текущие значения.
Watch (Наблюдение): Позволяет вручную добавить конкретные переменные или выражения, чтобы следить именно за их изменением при пошаговом выполнении кода.
Call Stack (Стек вызовов): Показывает последовательность (цепочку) вызовов функций, которые привели к текущей строке кода. Помогает понять, из какой функции мы попали в текущую.
