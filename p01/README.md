1) Признак «в наличии» лучше вычислять из количества, потому что можно случайно изменить количесво на 0, а признак оставить прежним. Получится ошибка ведь товара не будет, а система скажет, что он есть
2) Компьютеры хранят числа в двоичной системе. Дробь 0.1 в ней, как 1/3 в привычной десятичной, бескончная. Компьютер немного округляет ее. При сложении двух таких неточных чисел получаются цифры с кучей нулей (0.300000000000.4). Чтобы избежать таких ошибок при работе с деньгами, нужно считать в целых числах (в копейках), а на экран выводить в рублях
4) Третий. 
5) 5 + 3 -> 53. "+" склеивает строки
    "5" - 3 -> 2. "-" работает только с числами
    [] + {} -> "[object Object]" пустой массив превращается в пустую строку "", а объект в текст "[object Object]". Посклько мы складываем строку и текст, они просто склеиваются
    null == undefined -> получилось true. При двойном равно (==) JavaScript считает их одинаковыми, потому что оба этих значения означают «здесь ничего нет». (А вот при тройном === результат был бы false, так как это разные типы данных).
