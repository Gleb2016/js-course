Признак «в наличии» лучше вычислять из количества, потому что можно случайно изменить количесво на 0, а признак оставить прежним. Получится ошибка ведь товара не будет, а система скажет, что он есть
Компьютеры хранят числа в двоичной системе. Дробь 0.1 в ней, как 1/3 в привычной десятичной, бескончная. Компьютер немного округляет ее. При сложении двух таких неточных чисел получаются цифры с кучей нулей (0.300000000000.4). Чтобы избежать таких ошибок при работе с деньгами, нужно считать в целых числах (в копейках), а на экран выводить в рублях
