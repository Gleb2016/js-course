Чем Function Declaration отличается от Function Expression?
Function Declaration это когда мы просто пишем function f() {}. Такую функцию можно вызвать даже до того места, где она записана, потому что JavaScript сначала просматривает весь код и запоминает такие функции. 
Function Expression это когда функцию записывают в переменную: const f = function() {}. Здесь так не получится: пока программа не дошла до этой строки, вызывать функцию нельзя, будет ошибка. Ещё такая функция может быть без имени.
