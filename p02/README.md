1. Чем Function Declaration отличается от Function Expression?
Function Declaration это когда мы просто пишем function f() {}. Такую функцию можно вызвать даже до того места, где она записана, потому что JavaScript сначала просматривает весь код и запоминает такие функции. 
Function Expression это когда функцию записывают в переменную: const f = function() {}. Здесь так не получится: пока программа не дошла до этой строки, вызывать функцию нельзя, будет ошибка. Ещё такая функция может быть без имени.
2. Что получит параметр, если аргумент не передан? Когда срабатывает значение по умолчанию?
Параметр получит undefined. Значение по умолчанию срабатывает, когда аргумент не передан или передан undefined. На null, 0, '' и false оно не срабатывает.
3. Чем вывод через console.log отличается от возврата через return?
console.log только печатает значение в консоль, а функция при этом возвращает undefined. return отдаёт значение вызывающему коду, чтобы его можно было сохранить или использовать в вычислениях, и завершает функцию.
4. Почему () => { name: 'x' } возвращает undefined?
Фигурные скобки после стрелки воспринимаются как тело функции, а name: 'x' как метка (label) с выражением внутри. Оператора return нет, поэтому результат undefined. Чтобы вернуть объект, нужны круглые скобки: () => ({ name: 'x' })
5. Что такое лексическое окружение и цепочка областей видимости? Лексическое окружение это «хранилище» переменных и параметров, созданное для функции или блока при их выполнении, со ссылкой на внешнее окружение. При поиске имени движок смотрит в текущем окружении, затем в внешнем и так далее до глобального. Эта последовательность и есть цепочка областей видимости. Она определяется местом, где функция написана в коде, а не местом вызова.
6. Что такое замыкание? Почему count не исчезает после завершения createCounter?
Замыкание это функция вместе с ссылкой на окружение, в котором она создана. Внутренняя функция, возвращённая из createCounter, держит ссылку на его окружение, поэтому сборщик мусора не удаляет count, пока функция существует.
7. Зачем нужны внешние скобки в IIFE?
Без них строка function () {}... начинается с ключевого слова function и разбирается как Function Declaration, которой нужно имя, и получается синтаксическая ошибка. Скобки превращают конструкцию в выражение, и её можно сразу вызвать: (function () {})()
8. Что такое стек вызовов и почему рекурсия без базового случая вызывает RangeError?
Стек вызовов это структура, где движок хранит активные вызовы функций: каждый вызов добавляет запись, а возврат её убирает. Без базового случая функция вызывает себя бесконечно, стек переполняется, и движок выбрасывает RangeError: Maximum call stack size exceeded.

9. Почему функцию, объявленную через function, можно вызвать до объявления, а через const нельзя?
Function Declaration на первом этапе целиком попадает в память вместе с телом. const тоже регистрируется заранее, но не инициализируется до своей строки и находится во временной мёртвой зоне (TDZ). Обращение к ней раньше даёт ReferenceError.

10. Почему изменение поля объекта внутри функции видно снаружи, а присваивание параметру нового объекта нет?
В параметр копируется ссылка на объект, а не сам объект. Изменение item.qty++ идёт по ссылке в тот же объект, поэтому изменение видно снаружи. Присваивание item = {...} лишь перенаправляет локальную копию ссылки на новый объект, а внешняя переменная по-прежнему указывает на старый.
